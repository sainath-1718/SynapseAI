# SynapseAI

## An Autonomous Multi-Agent Platform for Machine Learning Automation

SynapseAI is an autonomous multi-agent platform focused on automating the complete machine learning workflow. It assists users from dataset analysis and preprocessing to model selection, training, evaluation, explainability, and report generation.

## Key Features

- Automated dataset analysis
- Missing-value and duplicate detection
- Identifier-column detection
- Automatic task detection
- Supervised learning workflow
- Unsupervised learning workflow
- Automated model recommendation
- Model training and evaluation
- SHAP-based explainability
- Experiment documentation
- Automated report generation
- Interactive ML execution interface

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Python
- Pyodide
- Pandas
- NumPy
- Scikit-learn
- SHAP

## Project Scope

SynapseAI currently focuses on tabular CSV datasets and provides automated machine learning workflows directly within the application.

## Future Scope

- Reinforcement learning module
- Advanced model optimization
- Support for larger datasets
- Additional machine learning algorithms
- Enhanced multi-agent orchestration
